Umbral Design System v0.1

Umbral

Backoffice y portal del comprador para gestionar créditos de vivienda en Colombia. Este documento muestra los tokens y componentes base. Los valores salen de design/tokens/tokens.json y se generan con build-tokens.mjs.

Color

Azul de confianza como color de marca, teal como acento para lo que avanza bien ("lista para radicar") y neutros fríos para que las tablas densas descansen. Los componentes usan siempre tokens semánticos, nunca las paletas directamente.
